# PitchDeck Studio

Build a web application called **PitchForge**.

PitchForge converts a project's README, documentation, or technical description into an investor-ready pitch deck.

For this first step, build ONLY the frontend foundation and UI. Do not implement mock blockchain payments or fake AI functionality yet.

Create a premium, modern SaaS-style interface with:

1. A landing page with:

   * Brand name: PitchForge

   * Tagline: "Your README is technical. Your pitch shouldn't be."

   * Short description explaining that PitchForge transforms technical documentation into investor-ready presentations.

   * Primary CTA: "Generate Pitch Deck"

   * Secondary option to upload a README file or paste documentation.

2. A main workspace containing:

   * README/documentation upload area

   * Drag-and-drop support

   * Text/paste input area

   * File name display after upload

   * Character/word count

   * Generate Pitch Deck button

3. A professional visual style:

   * Premium startup/SaaS appearance

   * Excellent typography

   * Clean spacing

   * Subtle animations

   * Responsive design

   * Avoid generic AI-looking gradients

   * Make the interface feel like a real commercial product

4. Include a small trust/status area showing:

   "Pay-per-generation • x402 • Algorand"

5. Do NOT build:

   * Authentication

   * User accounts

   * Database

   * Fake payment flow

   * Fake blockchain transaction

   * Mock AI generation

   * Dashboard

   * Unnecessary features

Structure the application so that we can later connect:

* OpenAI API

* x402 payment

* Algorand

* PPTX/PDF generation

The UI should be production-quality and ready for backend integration.
